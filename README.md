# Веб-приложения сервиса доставки еды 

Final - Фронтенд-приложение для просмотра каталога товаров, управления корзиной и оформления заказов с личным кабинетом пользователя. Проект реализован на чистом стекe веб-технологий без использования сторонних библиотек и фреймворков.

## 🚀 Технологический стек

* **HTML5**: Семантическая разметка (`<header>`, `<main>`, `<aside>`, `<footer>`, `<form>`, `<table>`).
* **CSS3**: Чистый CSS, Flexbox-сетки, адаптивный дизайн (`@media`-запросы под мобильные устройства и планшеты), модальные окна и кастомные уведомления.
* **JavaScript (ES6+)**: Vanilla JS без сторонних библиотек.
* **API & Хранение данных**:
  * **Fetch API (Async/Await)** — взаимодействие с REST API (`edu.std-900.ist.mospolytech.ru`).
  * **LocalStorage** — сохранение состояния корзины и кэширование заказов.

## Функциональность final

### Каталог товаров и меню
* Динамическая загрузка списка товаров с сервера (`GET /api/goods`, `GET /api/dishes`).
* Отображение карточек с ценами, скидками и рейтингами.
* Фильтрация товаров по категориям и видам.

### Корзина и оформление заказа
* Добавление и удаление позиций из корзины с сохранением состояния при перезагрузке страницы (`LocalStorage`).
* Динамический перерасчет стоимости с учетом скидок и наценки за доставку (в зависимости от дня недели и времени).
* Проверка корректности данных и отправка заказа на сервер (`POST /api/orders`).

### Личный кабинет
* Просмотр истории заказов в виде интерактивной таблицы (`GET /api/orders`).
* Просмотр подробностей заказа в модальном окне.
* Редактирование данных заказа (`PUT /api/orders`): имя, адрес, интервал доставки.
* Удаление заказа из системы (`DELETE /api/orders`) с подтверждением.
